# Support

## Project status

This repository is currently a pre-release implementation blueprint. The scripts described in the README are not yet included, and production support is not available.

## Getting help

Before opening an issue:

1. Confirm the referenced script or configuration file exists in the repository.
2. Review the README prerequisites and troubleshooting sections.
3. Remove credentials, DNS queries, device names, MAC addresses, private addresses, internal hostnames, site identifiers, and generated reports from any diagnostic material.
4. Reproduce the problem with placeholder or sanitized values where possible.

Use the bug-report template for reproducible defects and the feature-request template for proposed improvements. General Pi-hole, UniFi, OpenClaw, shell, macOS, or Linux support questions may be better suited to those projects' official support channels.

## Security issues

Do not use a public issue for a vulnerability or sensitive data exposure. Follow [SECURITY.md](SECURITY.md).
